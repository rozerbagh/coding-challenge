# Web application

Next.js App Router frontend for the Product Catalogue MVP. It consumes the NestJS REST API; it does not call Fake Store API directly.

From the repository root, use `npm run dev:web` for local development and set `API_INTERNAL_BASE_URL=http://localhost:3001/api/v1` for the web server's API calls. See the root [README](../../README.md) for the complete setup, routes, configuration, architecture, and verification commands.
